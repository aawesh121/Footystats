# 12-Week Roadmap (50/50)

Tick a week when **both** friends can explain it.

| Week | Topic | Friend 1 | Friend 2 | Goal |
|---|---|---|---|---|
| 1 | Basics | Tiny practice page | Tiny practice page | Both understand the project |
| 2 | Dataset | Explore `player_profiles` | Explore `player_performances` | Both understand `player_id` links |
| 3 | Git/GitHub | Own feature branch | Own feature branch | Safe collaboration |
| 4 | Database | Design `players` table | Design `performances` table | Both know whole schema |
| 5 | Flask | One route | Another route | Browser → Flask → DB → HTML |
| 6 | Search | Backend + SQL | Search box + result UI | Working search, then swap review |
| 7 | Profile | Profile UI | Backend query for player | Search → click → profile |
| 8 | Statistics | Query season/team data | Stats table + display | Correct stats shown |
| 9 | Analysis | Totals, contributions | Per-90, best season | Verified formulas |
| 10 | Visualization | Prepare chart data | Chart.js chart | One useful chart |
| 11 | Testing | Backend/DB/calcs | UI/forms/responsive | Swap, report bugs |
| 12 | Final | Report, diagrams, slides | Report, diagrams, slides | Both demo whole system |

## Equal contribution checklist
- [ ] Both write code
- [ ] Both work with data
- [ ] Both learn SQL and SQLite
- [ ] Both learn Flask
- [ ] Both learn HTML/CSS/Bootstrap/Jinja
- [ ] Both learn Git/GitHub
- [ ] Both test the application
- [ ] Both review each other's code
- [ ] Both contribute to documentation
- [ ] Both can explain the complete system
